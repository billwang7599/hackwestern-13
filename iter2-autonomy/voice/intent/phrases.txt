# TARS voice: training phrases for the intent classifier.
#
# Format: one phrase per line,   intent<TAB>phrase
#   - intents: forward back left right turn_around stop goto spin status scan forget memory recall unknown
#   - write it the way a person says it, WITHOUT the wake word ("TARS, ..." is added automatically)
#   - lowercase, no punctuation needed; train.py adds capitals, punctuation and whisper mistakes
#   - {n} = a turn amount ("90", "forty five degrees", "a bit" ...)
#   - {d} = a distance   ("half a metre", "two steps", "50 centimeters" ...)
#   - {o} = an object from objects.txt ("trash can", "bin", "chair" ...)
#   - '#' starts a comment. A phrase may only be listed under ONE intent (train.py checks).
#
# After editing:   python3 iter2-autonomy/voice/intent/train.py      (retrains, rewrites intent_model.h, runs the tests)
# Try it:          python3 iter2-autonomy/voice/intent/try.py
#
# About 1 in 5 phrases of 2+ words (picked by a fixed hash) is held out of
# training and used to measure accuracy on phrasings the model has never seen.
# One-word phrases are always trained on.
