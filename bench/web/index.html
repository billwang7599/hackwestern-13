How to use the TARS bench

  1. Check the badge. SIM means a simulated car on this laptop; REAL ROBOT means the real one moves.
  2. Talk to it in the box on the left: type a command (or hold T / the 🎤 button and speak), or click a suggestion like “go to the trash can”. Keep Send to robot on, or it's only a dry run.
  3. Watch the map. The car, the route it plans and what it sees are drawn in the middle. The top bar says what it's doing.
  4. Drive by hand by holding WASD or the arrow keys (click the map first so the page has focus).
  5. Stop any time: the red STOP button or Space.

Everything else (robot status, the room editor and faults, map demos, the voice lab, tests, logs) is under More tools at the top. It opens beside the map.
