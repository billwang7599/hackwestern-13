How to use the TARS bench

  1. Demo in four steps (Drive page, top): pick a room → 🚗 Car to start → say or type “go to the trash can” → watch the route on the map. The strip under the header always says what go-to is doing (Idle, Planning, Searching, Driving, Arrived, Failed + why).
  2. Check the badge. SIM means a simulated car on this laptop; REAL ROBOT means the real one moves.
  3. Pick a page in the bar under the header: Drive (talk, drive, map), Room (edit the sim room, delete things), Memory (what the robot remembers; forget things), Voice lab, Car, Tests, Mission. Keys 1…7 switch pages. Each page starts with a What’s this page for? box, and ⓘ next to a section title says what that section does.
  4. Talk to it on the Drive page: type a command (or hold T / 🎤 and speak), or click a suggestion like “go to the trash can”. Keep Send to robot on, or it's only a dry run.
  5. Drive by hand: hold WASD or the arrow keys (click the map first so the page has focus).
  6. Stop any time, on any page: the red STOP button, Space or Esc.
