How to use the TARS bench

  1. Check the badge. SIM means a simulated car on this laptop; REAL ROBOT means the real one moves.
  2. Pick a page in the bar under the header: Drive (talk, drive, map), Room (edit the sim room, delete things), Memory (what the robot remembers; forget things), Voice lab, Car, Tests, Mission. Keys 1…7 switch pages. Each page starts with a What’s this page for? box, and ⓘ next to a section title says what that section does.
  3. Talk to it on the Drive page: type a command (or hold T / 🎤 and speak), or click a suggestion like “go to the trash can”. Keep Send to robot on, or it's only a dry run.
  4. Drive by hand: hold WASD or the arrow keys (click the map first so the page has focus).
  5. Stop any time, on any page: the red STOP button or Space.
